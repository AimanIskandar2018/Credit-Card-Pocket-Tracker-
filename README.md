# Pocket Tracker — Yaboyman

A personal credit card rewards tracker. No bank connection, no server database.

## GitHub Pages

1. Create a **public** repository named `pocket-tracker` on GitHub.
2. Upload all five files in this folder to the repository **root** (not a subfolder).
3. Go to **Settings → Pages**. Select **Deploy from a branch**, **main**, and **/(root)**. Save.
4. Visit `https://YOUR-USERNAME.github.io/pocket-tracker/` in Safari on your iPhone.
5. Tap Share → Add to Home Screen → Add (select Open as Web App if shown).

**Privacy:** GitHub Pages is public. The app code is public, but transactions saved in browser localStorage are *not* uploaded to GitHub. Do not put actual financial transactions in the repository. Export backups regularly, because browser data may be cleared. No cross-device sync.

**Notes:** App calculates *estimates*, not bank-certified rewards. Transactions should be logged using posted dates for statement-cycle allocation. Maybank weekend rewards depend on purchase day and exclusions. Install via Safari at the same URL you plan to keep. Confirm eligibility against latest UOB/Maybank terms.
