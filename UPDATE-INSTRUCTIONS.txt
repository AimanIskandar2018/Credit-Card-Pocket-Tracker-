POCKET TRACKER V21.0 — CLEAN PURCHASE DATE + NEW GRADIENT THEMES

FILES TO REPLACE: index.html and sw.js in the main/root folder of your GitHub repository.
Do not move the assets/celebrations folder or any app icons.

WHAT CHANGED
• Purchase date: compact, left-aligned label and calendar icon; tapping opens the native date picker.
• Settings > Profile > App colour: added Sunset orange and Fresh green gradients.
• Previous white, purple and grey themes remain, as do your saved name and spending records.
• Both new themes have coloured gradients on the background, main action buttons, progress bars and UOB card.
• Kept V20.2's single reaction popup, soft fade-out and horizontal swipe fixes.

UPDATE GITHUB
1. Open Pocket Tracker Settings > Backup & other options > Export backup (recommended).
2. Extract ZIP. Go to the repo main folder. Add file > Upload files.
3. Upload index.html and sw.js and commit changes, replacing the two existing files.
4. Check GitHub Pages deployment, then load the site/app. Footer should say v21.0.
5. In Settings > Profile, choose Sunset orange or Fresh green, then Save settings.
6. Open Log spending and tap Purchase date. Confirm the iPhone date picker opens.

If your installed Home Screen app still shows v20.2, use its check for updates option, then close/reopen it. Avoid deleting the app / clearing storage before exporting a backup.
